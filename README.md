# Project Rebound — Frontend (Development)

This repository contains the **development frontend** for Project Rebound, a book scanning, inventory management, and resale platform.

The frontend is built using **Vue.js and Ionic Capacitor**, supporting a responsive web experience and future mobile application deployment.

### Purpose
This environment is used for active frontend development, feature implementation, UI/UX improvements, integration testing, and validation before production deployment.

### Technology Stack
- **Frontend:** Vue.js
- **Mobile Framework:** Ionic Capacitor
- **Backend & Database:** Supabase (PostgreSQL)
- **Hosting & Deployment:** Railway
- **Environment:** Development

### Development Workflow
All new frontend features, updates, and bug fixes should be implemented and tested in the development environment before being promoted to production.

**Note:** This environment is intended for development and testing only and should not be used for live customer operations.
